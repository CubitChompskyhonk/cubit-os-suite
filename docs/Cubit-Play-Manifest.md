# Cubit Play Manifest v1

## Product
**Cubit Play** — virtual console for **first-party** Cubit games.

## Graphics profile: `n64-class`
- Era-inspired presentation (limited res feel, optional CRT)
- Not a claim of Nintendo compatibility or official license
- Default experience packs allowed (CRT on console shell)

## Catalog
Games listed in `play/catalog.json` with signed/local paths only.

## Split
| Mode | Content |
|------|---------|
| **Cubit Play** | Under the Glow + future Cubit titles |
| **Labs** | Chip-8, generic experiments, pack tools |

## Session
`localStorage.cubit_play_session` — game id, profile, timestamp.
